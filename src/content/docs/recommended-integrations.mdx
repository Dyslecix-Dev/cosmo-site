## Delivery & reach

### i18n

Route and translate content for multilingual sites.

- <a href="https://docs.astro.build/en/guides/internationalization/" target="_blank" rel="noopener noreferrer">Astro i18n routing</a> — Built into Astro. Locale-prefixed routes, fallbacks, and translation helpers without a third-party plugin.

### PWA

Have a website also behave as a mobile app with offline availability.

- <a href="https://vite-pwa-org.netlify.app/frameworks/astro.html#astro-integration" target="_blank" rel="noopener noreferrer">Vite PWA</a> — The standard choice in the Vite ecosystem. Generates a service worker and manifest, and handles offline caching.

### Script offloading

Move third-party scripts (analytics, chat widgets, ads) off the main thread.

- <a href="https://docs.astro.build/en/guides/integrations-guide/partytown/" target="_blank" rel="noopener noreferrer">Partytown</a> — An Astro integration that runs third-party scripts inside a web worker.

## UI building blocks

### Front-end framework

Astro is HTML-first, but you can drop in islands of any major framework when you need real interactivity.

- <a href="https://docs.astro.build/en/guides/integrations-guide/alpinejs/" target="_blank" rel="noopener noreferrer">Alpine.js</a> — Zero bundle cost with no hydration overhead, but is too limited for anything beyond simple UI state or component reuse. Best used for dropdowns, modals, and toggling CSS classes.
- <a href="https://docs.astro.build/en/guides/integrations-guide/preact/" target="_blank" rel="noopener noreferrer">Preact</a> — Deliver React compatibility at a fraction of the bundle size, but some React libraries break under compat mode in non-obvious ways. Best used for replacing React islands, reusing hooks, and lightweight interactive widgets.
- <a href="https://docs.astro.build/en/guides/integrations-guide/react/" target="_blank" rel="noopener noreferrer">React</a> — An unmatched ecosystem, but it carries the heaviest hydration cost of the group and is overkill for simple islands. Best used for dashboards, multi-step forms, and anything needing React-specific libraries.
- <a href="https://docs.astro.build/en/guides/integrations-guide/solid-js/" target="_blank" rel="noopener noreferrer">SolidJS</a> — The finest-grained reactivity of the group with no virtual DOM overhead, but has the smallest ecosystem. Best used for live feeds, real-time counters, and performance-critical reactive UIs.
- <a href="https://docs.astro.build/en/guides/integrations-guide/svelte/" target="_blank" rel="noopener noreferrer">Svelte</a> — The most readable syntax and the best built-in animation primitives of the group, but some patterns don't translate cleanly into Astro's island model. Best used for animated components, filterable lists, and form-heavy islands.
- <a href="https://docs.astro.build/en/guides/integrations-guide/vue/" target="_blank" rel="noopener noreferrer">Vue</a> — Its single file component structure and ecosystem are mature and ergonomic, but has nothing that really stands out against other frameworks. Best used for tabs, interactive widgets, and teams already familiar with Vue.

### Component library

Pre-built accessible components for fast development.

- <a href="https://starwind.dev/docs/getting-started/installation/" target="_blank" rel="noopener noreferrer">Starwind UI</a> — Astro-native, copy-in components built on Tailwind.
- <a href="https://daisyui.com/docs/install/astro/" target="_blank" rel="noopener noreferrer">daisyUI</a> — Class-based component layer built on top of Tailwind.

### Icon library

A consistent icon set that doesn't ship the entire pack to the browser.

- <a href="https://lucide.dev/guide/astro/getting-started" target="_blank" rel="noopener noreferrer">Lucide</a> — Clean, opinionated, MIT-licensed icon set forked from Feather.
- <a href="https://www.astroicon.dev/getting-started/" target="_blank" rel="noopener noreferrer">Astro Icon</a> — Pull static SVGs from the Iconify set.

### Animation library

For animations that go beyond what CSS keyframes can easily handle.

- <a href="https://auto-animate.formkit.com/#installation" target="_blank" rel="noopener noreferrer">AutoAnimate</a> — Lightweight library for smooth transitions, but limited granular control.
- <a href="https://motion.dev/docs/quick-start" target="_blank" rel="noopener noreferrer">Motion</a> — Middle of the pack when it comes to animations, but is overreaching for more complex motion.
- <a href="https://gsap.com/docs/v3/Installation" target="_blank" rel="noopener noreferrer">GSAP</a> — The most powerful and precise option, but is overkill for simple animations.

## Authoring & content

### CMS

Allows for content edits without opening a code editor.

- <a href="https://docs.astro.build/en/guides/cms/tina-cms/" target="_blank" rel="noopener noreferrer">Tina CMS</a> — Git-based, visual editor that keeps content in source control. Note the in-page visual editing piece is still flagged as experimental for Astro.
- <a href="https://docs.astro.build/en/guides/cms/decap-cms/" target="_blank" rel="noopener noreferrer">Decap CMS</a> — Open-source successor to Netlify CMS.

### Mermaid diagram

Render flowcharts and sequence diagrams.

- <a href="https://github.com/joesaby/astro-mermaid" target="_blank" rel="noopener noreferrer">astro-mermaid</a> — In-browser rendering specifically for Astro.

### Embed content

Embed YouTube, Vimeo, tweets, etc. without affecting performance.

- <a href="https://astro-embed.netlify.app/getting-started/" target="_blank" rel="noopener noreferrer">Astro Embed</a> — Lazy-loaded, lightweight wrappers for the common embed providers.

### OG image generation

Per-page social cards so links to the site look good when shared on social platforms.

- <a href="https://github.com/delucis/astro-og-canvas/tree/latest/packages/astro-og-canvas" target="_blank" rel="noopener noreferrer">astro-og-canvas</a> — Build-time programmatic generation. Define a card template in code and an image renders for every page during `astro build`.
- <a href="https://ogimagemaker.com/" target="_blank" rel="noopener noreferrer">OG Image Maker</a> — Hosted designer for one-off cards. Useful when you want a hand-crafted image for the homepage or a marquee page without writing a template.

## Backend-as-a-service

### Forms

Since static sites can't handle POST on their own.

- <a href="https://web3forms.com/features" target="_blank" rel="noopener noreferrer">Web3Forms</a> — Just `action="https://api.web3forms.com/submit"` plus an access key. No backend, a free tier, and spam filtering included.

### Email

Transactional email (contact form, password reset, receipts) from a real API.

- <a href="https://resend.com/features/email-api" target="_blank" rel="noopener noreferrer">Resend</a> — Developer-first API with a generous free tier.

### Newsletter

A list and an editor for sending updates.

- <a href="https://buttondown.com/pricing" target="_blank" rel="noopener noreferrer">Buttondown</a> — Markdown-first, indie-friendly pricing, embeddable subscribe form.

### Comments

Reader discussion under blog posts or docs.

- <a href="https://remark42.com/docs/getting-started/installation/" target="_blank" rel="noopener noreferrer">Remark42</a> — Self-hosted, lightweight, and supports anonymous and OAuth.

### Search

Client-side full-text search.

- <a href="https://github.com/shishkin/astro-pagefind" target="_blank" rel="noopener noreferrer">Astro-Pagefind</a> — Wraps Pagefind, which builds a static search index from your `dist/` output and ships a tiny runtime.

### Payments

Handle payment processing.

- <a href="https://docs.astro.build/en/guides/ecommerce/#paddle" target="_blank" rel="noopener noreferrer">Paddle</a> — Merchant of record that handles global tax and compliance. Best for SaaS and digital products.
- <a href="https://docs.astro.build/en/guides/ecommerce/#lemon-squeezy" target="_blank" rel="noopener noreferrer">Lemon Squeezy</a> — Merchant of record acquired by Stripe in 2024 and being folded into Stripe Managed Payments. Existing accounts still work, but new projects should weigh whether to start on Lemon Squeezy or jump straight to the Stripe successor.
- <a href="https://ko-fi.com/features" target="_blank" rel="noopener noreferrer">Ko-fi</a> — Simple tipping/membership/commissions widget that is NOT a merchant of record.

## Media & state

### Media CDN

Offload images and video to a service that resizes, formats, and caches them globally.

- <a href="https://docs.astro.build/en/guides/media/cloudinary/" target="_blank" rel="noopener noreferrer">Cloudinary</a> — Mature transform pipeline (resize, crop, format, AI) with a generous free tier.

### State

Share reactive state between islands.

- <a href="https://docs.astro.build/en/recipes/sharing-state/" target="_blank" rel="noopener noreferrer">Nano Stores</a> — Sub-1 kB, framework-agnostic atoms. Astro's recommended way to share state between React, Svelte, and Vue islands on the same page.

## Observability

### Analytics

Traffic insight that respects privacy.

- <a href="https://umami.is/features" target="_blank" rel="noopener noreferrer">Umami</a> — Self-hostable, cookieless, and GDPR-friendly (General Data Protection Regulation).

### Error tracking

Monitor runtime errors.

- <a href="https://docs.astro.build/en/guides/backend/sentry/" target="_blank" rel="noopener noreferrer">Sentry</a> — Industry-standard error and performance monitoring.

## Quality & developer experience

### Git hook

Pre-commit / pre-push automation so lint, format, and typecheck run at certain steps.

- <a href="https://lefthook.dev/#how-to-install-lefthook" target="_blank" rel="noopener noreferrer">Lefthook</a> — Single Go binary, parallel hook execution, and one YAML config.

### Environment variables

Type-safe, validated access to env vars at build and runtime.

- <a href="https://docs.astro.build/en/guides/environment-variables/#getting-environment-variables" target="_blank" rel="noopener noreferrer">astro:env</a> — Built into Astro. Declare each variable's type and whether it's public/secret in `astro.config.mjs`.

### Unit & integration test

Test utilities, components, and basic logic.

- <a href="https://docs.astro.build/en/guides/testing/#vitest" target="_blank" rel="noopener noreferrer">Vitest</a> — The default testing tool for all projects.

### E2E test

Simulate user workflow through your app.

- <a href="https://docs.astro.build/en/guides/testing/#playwright" target="_blank" rel="noopener noreferrer">Playwright</a> — Cross-browser, parallel, and a great trace viewer. The current default for E2E testing.
- <a href="https://docs.astro.build/en/guides/testing/#cypress" target="_blank" rel="noopener noreferrer">Cypress</a> — Alternative if you prefer a time-travel debugger and interactive authoring.

### a11y testing

Catch contrast, ARIA, and structural issues before they reach users.

- <a href="https://chromewebstore.google.com/detail/axe-devtools-web-accessib/lhdoppojpmngadmnindnejefpokejbdd" target="_blank" rel="noopener noreferrer">axe DevTools</a> — Industry standard Chrome extension that audits the page in DevTools with rule explanations and remediation hints.
- <a href="https://chromewebstore.google.com/detail/wave-evaluation-tool/jbbplnpkjmmeebjpijfedlgcdilocofh" target="_blank" rel="noopener noreferrer">WAVE Evaluation Tool</a> — Chorme extension with a visual overlay that pins issues directly on the rendered page.

### Link checking

Find broken internal and external links.

- <a href="https://lychee.cli.rs/guides/getting-started/" target="_blank" rel="noopener noreferrer">Lychee</a> — Fast Rust CLI that checks every link in `dist/` or your repo.

### Bundle analysis

Visual your project's size and weight.

- <a href="https://sonda.dev/frameworks/astro" target="_blank" rel="noopener noreferrer">Sonda</a> — Vite/Astro-native bundle visualizer that highlights duplicated deps and oversized modules.
